# Segurança

Não publique dados clínicos, credenciais ou URLs assinadas em issues.
Reporte vulnerabilidades pela função de aviso privado de segurança do
repositório, quando disponível. Um relato deve conter uma entrada sintética,
o comportamento esperado, o observado e a versão afetada.

Use `NODE_ENV=production` em produção. A biblioteca é um componente técnico,
não uma aplicação clínica pronta ou um serviço médico certificado.
