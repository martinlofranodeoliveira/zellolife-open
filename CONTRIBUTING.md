# Contribuir

Implemente correções e recursos úteis em mudanças pequenas e completas.
Inclua um teste que demonstre o comportamento, execute `npm run check` e
descreva o problema resolvido no pull request.

Use apenas dados sintéticos. Não inclua documentos, imagens, gravações, nomes,
identificadores ou configurações de uma instalação real. Recursos que usam
rede devem receber configuração explícita e ser testados com mocks.

O projeto aceita contribuições humanas e assistidas por IA. Quem envia uma
contribuição deve revisar seu código, ter direito de licenciá-lo sob MIT e
verificar os testes. Não produza commits vazios, alterações cosméticas em
massa ou código sem propósito para aumentar contagens de atividade.

O CLI aceita arquivos ou stream de entrada padrão com limite de bytes e
validação estrita de UTF-8. Próximas melhorias úteis: declarações TypeScript,
testes de invariantes do sanitizador e documentação de integração com aplicações
de terceiros. Evite acrescentar uma dependência de nuvem ao núcleo.
